# Version 0.1.0

> **Navigation**: [Roadmap](./README.md) | [Documentation Root](../README.md)

The minimal binding against Keleusma 0.2.2. The tasks are ordered so that each depends
only on the ones before it. The first task settles the main design risk.

| # | Task | Done when |
|---|---|---|
| 1 | Own the arena and VM together in a `#[pyclass]`, using `self_cell` | A test constructs, calls and drops many VMs, and the process's memory does not grow with the count |
| 2 | `keleusma.compile(source)` returning a module | A compile error raises an exception carrying the line and column of the `Span` |
| 3 | `keleusma.VM(module)` with an automatically sized arena | A module that fails verification raises, and the message names the failure |
| 4 | Scalar, string, tuple and array conversion | Round trips pass, and out-of-range integers and bytes raise instead of wrapping |
| 5 | `vm.call`, `vm.resume` and the state result | A script that yields three values and then finishes is driven to completion |
| 6 | `vm.stream(...)` as a generator | Iteration ends on `Finished`, and a `Reset` has a stated meaning |
| 7 | `vm.register(name, callable)` | A Python exception raised inside a native reaches the caller as a Python exception, not as a crash |
| 8 | Examples | A PyGame frame loop that resumes once per frame, and a NumPy reduction passing lists, each run in a test or a documented manual check |
| 9 | Documentation of the guarantee boundary | The README states that worst-case bounds cover the script and declared native bounds, not Python code |
| 10 | Continuous integration | Lint, type checks and tests on Linux and macOS for Python 3.12 and the newest release |

Out of scope for 0.1.0, as recorded in the design: fixed-point values beyond a stated
choice, structs and enums, zero-copy NumPy buffers, precompiled bytecode, hot swap,
signed modules, free-threaded Python and a PyPI release. Publishing needs the operator's
confirmation in session.
