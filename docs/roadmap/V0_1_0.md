# Version 0.1.0

> **Navigation**: [Roadmap](./README.md) | [Documentation Root](../README.md)

The minimal binding against Keleusma 0.2.2. The tasks are ordered so that each depends
only on the ones before it. The first task settles the main design risk.

| # | Task | Done when | Status |
|---|---|---|---|
| 1 | Own the arena and VM together in a `#[pyclass]`, using `self_cell` | A test constructs, calls and drops many VMs, and the process's memory does not grow with the count | Done 2026-10-24 |
| 2 | `keleusma.compile(source)` returning a module | A compile error raises an exception carrying the line and column of the `Span` | Done 2026-10-25 |
| 3 | `keleusma.VM(module)` with an arena sized to survive `Reset` and composite arguments | A module that fails verification raises, and the message names the failure, and a stream runs 10,000 iterations with tuple arguments in an automatically sized arena | Open |
| 4 | Scalar, string, tuple, array and `Fixed` conversion, decoding composites by the entry point's declared types | Round trips pass for every shape in the Dromon probe, a `Fixed` round trips exactly, and out-of-range integers and bytes raise instead of wrapping | Open |
| 5 | `vm.call`, `vm.resume` and the state result | A script that yields three values and then finishes is driven to completion, and 1,000 VMs created on one thread are each resumed in turn | Open |
| 5b | `vm.wcet_per_iteration` and `vm.arena_capacity` | Both are readable from Python, and the documentation states their units and that they cover only the script and declared native bounds | Open |
| 6 | `vm.stream(...)` as a generator | Iteration ends on `Finished`, and a `Reset` has a stated meaning | Open |
| 7 | `vm.register(name, callable)` and `vm.set_native_bounds` | A Python exception raised inside a native reaches the caller as a Python exception, not as a crash, and declared bounds are either covered by the arena or rejected | Open |
| 8 | Examples | A PyGame frame loop that resumes once per frame, a NumPy reduction passing lists, and a batched update loop in Dromon's event and action shape, each run in a test or a documented manual check | Open |
| 9 | Documentation of the guarantee boundary | The README states that worst-case bounds cover the script and declared native bounds, not Python code | Open |
| 10 | Continuous integration | Lint, type checks and tests on Linux and macOS for Python 3.12 and the newest release | Done 2026-10-25 |

Tasks 4 and 7 grew on 2026-10-24, when the operator decided that `Fixed` converts to an
exact Python value and that native bounds are exposed. The design records both choices
and the risk each carries. Task 3 removes the temporary `_OwnedVmProbe` class that task 1
added for its tests.

Tasks 3, 4, 5 and 8 grew, and task 5b was added, on 2026-10-25, when the operator
approved the changes proposed for Dromon, the first project to plan on this binding. Its
needs are in `docs/architecture/KELEUSMA_INTEGRATION.md` of the `pydromon` repository.
Task 3 also fixes a defect in task 1, whose arena is too small after the first `Reset`.
Task 7 stays in 0.1.0 after the tasks Dromon needs, because Dromon uses no natives.

Task 10 was done early, on 2026-10-25, at the operator's instruction, so that every
later task merges through a remote check. It tests Python 3.12 and 3.15.

Out of scope for 0.1.0, as recorded in the design: structs and enums, zero-copy NumPy
buffers, precompiled bytecode, hot swap, signed modules, free-threaded Python and a PyPI
release. Publishing needs the operator's confirmation in session.
